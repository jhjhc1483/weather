# 기상예보 상황판

양평 · 경산 · 사천 · 함안 · 성주 · 세종 · 계룡 · 임실 8개 지역의 기상 항목을 표 한 장으로 띄우고
매시 갱신합니다.

```
┌──────────────────┬─────────────────┬──────────┬─ … ─┐
│ 구분             │      양평       │   경산   │ …   │
├──────────────────┼─────────────────┼──────────┼─────┤
│ 개황             │ 흐림 (이후 비)  │ …
│ 미세먼지  미세   │ ● 좋음 22       │ …
│           초미세 │ ● 보통 24       │ …
│ 기온 (℃)        │ 25~30           │ …
│ 풍향/풍속        │ ⇗ 남서풍 1~2m/s │ …
│ 일일 누적 강수량 │ 6.8mm           │ …
│ 일일 예상 강수량 │ 내일 01:00~05:00 (17mm) │
│ 기상특보         │ —               │ 폭염경보 │ …
└──────────────────┴─────────────────┴──────────┴─────┘
```

# 1. API 키 발급

**공공데이터포털 계정 하나로 키 하나만 받으면 됩니다.** 인증키는 계정 단위로 발급되고,
활용신청이 승인된 모든 API에 그 키를 그대로 씁니다. API마다 다른 키를 받는 게 아닙니다.

### 1) 회원가입과 본인인증

<https://www.data.go.kr> 회원가입 → **휴대전화 본인인증까지 완료.**
연락처 등록을 안 하면 API 이용 자체가 막힙니다.

### 2) 아래 5개를 각각 [활용신청]

| API | 이 프로젝트에서 쓰는 곳 |
|---|---|
| 기상청_단기예보 조회서비스 | 개황 · 기온 · 풍향/풍속 · 누적/예상 강수량 |
| 기상청_단기예보 통보문 조회서비스 | 기상개황 통보문 전문 |
| 기상청_기상특보 조회서비스 | 기상특보 |
| 한국환경공단_에어코리아_대기오염정보 | 미세먼지 · 초미세먼지 |
| 한국환경공단_에어코리아_측정소정보 | 지역별 측정소 자동탐색 |

포털 검색창에 위 이름을 그대로 붙여넣으면 나옵니다. 각 상세 페이지에서 **[활용신청]** →
활용목적(예: 부대 기상 상황판 운용) 기재 → 신청. **개발계정은 자동승인**이지만
기상청 API는 실제 호출이 열리기까지 몇 시간~하루가 걸릴 수 있습니다.
신청 직후 401/등록되지 않은 키 오류가 나면 대개 기다리면 풀립니다.

### 3) 키 복사

**마이페이지 → 데이터활용 → Open API → 개발계정** 에서 인증키를 봅니다.
`일반 인증키(Encoding)` 와 `일반 인증키(Decoding)` 두 가지가 보이는데,
**반드시 Decoding 값**을 씁니다. 이 코드는 `requests` 의 params 딕셔너리로 키를 넘기고
requests 가 알아서 URL 인코딩하므로, Encoding 키를 넣으면 `%` 가 두 번 인코딩되어
`SERVICE KEY IS NOT REGISTERED ERROR` 가 납니다.

### 4) 넣는 위치

| 실행 방식 | 넣는 곳 |
|---|---|
| 내 PC | 프로젝트 루트 `.env` 의 `DATA_GO_KR_KEY` |
| GitHub Actions | 저장소 **Settings → Secrets and variables → Actions → New repository secret**, 이름 `DATA_GO_KR_KEY` |

`.env` 는 `.gitignore` 에 걸어뒀습니다. 키가 커밋에 섞여 올라가지 않게 확인하세요.

> 개발계정 트래픽은 API당 **하루 10,000건**입니다.
> 8개 지역 × 시간당 약 20콜 × 24시간 ≈ 3,800건이라 여유가 있습니다.
> 안정화 후 운영계정으로 올리면 상향 신청할 수 있습니다.

# 2. GitHub + Vercel 배포

**결론: 가능합니다. 다만 Vercel에 파이썬 서버를 올리는 방식은 안 됩니다.**

이유가 셋입니다.

1. Vercel은 서버리스라 **상주 프로세스가 없습니다.** 매시 도는 백그라운드 스레드가 뜨지 않습니다.
2. **파일시스템이 휘발성**입니다. 누적 강수량처럼 시간에 걸쳐 쌓아야 하는 상태를 못 들고 있습니다.
3. Vercel Cron은 **Hobby 플랜에서 하루 1회**로 제한됩니다. `0 * * * *` 같은 매시 표현식은
   배포 단계에서 아예 거부됩니다. 매시 돌리려면 Pro($20/월)로 올리거나 외부 스케줄러를 붙여야 합니다.

그래서 **수집은 GitHub Actions, 배포는 Vercel 정적 호스팅**으로 갈랐습니다.
Actions가 매시 돌며 `public/data.json` 을 만들어 커밋하고, 그 푸시가 Vercel 재배포를 자동으로 물립니다.
Vercel 쪽에는 함수가 하나도 없어서 cron 제한과 무관하고, 전부 무료 범위입니다.
누적 강수량 상태가 `state/` 에 커밋되므로 이력도 git에 그대로 남습니다.

```
   GitHub Actions (매시)          Vercel
   ─────────────────────          ──────
   collect.py                     public/index.html   ← 정적
     ├→ 공공데이터포털 API 호출     public/data.json    ← Actions가 갱신
     ├→ public/data.json 쓰기            ↑
     └→ state/ 갱신 후 커밋 ─────────────┘ 푸시 → 자동 재배포
```

### 배포 절차

1. **저장소 생성 후 푸시.** `git init && git add . && git commit && git push`
2. **Secret 등록** — 위 1-4의 `DATA_GO_KR_KEY`
3. **Actions 최초 1회 수동 실행** — Actions 탭 → `기상자료 수집` → **Run workflow**.
   스케줄 트리거는 워크플로가 기본 브랜치에서 한 번 돌아야 붙는 경우가 많습니다.
   `public/data.json` 이 커밋되면 성공입니다.
4. **Vercel에서 Import** — <https://vercel.com/new> 에서 저장소 선택.
   Framework Preset **Other**, Build Command **비움**, Output Directory **`public`**.
   `vercel.json` 에 같은 설정이 들어 있어서 대개 그대로 잡힙니다.
5. 끝. 이후 Actions가 매시 커밋할 때마다 Vercel이 알아서 다시 배포합니다.

### 배포하면서 걸릴 만한 것들

- **Vercel Hobby는 Git 조직(Organization) 소유 저장소를 연결하지 못합니다.**
  개인 계정 저장소로 만들거나 Vercel 팀을 만들어야 합니다.
- **Actions 스케줄은 정시를 보장하지 않습니다.** 부하에 따라 5~30분 늦는 일이 흔합니다.
  기준시각은 실행된 시점의 정시로 찍히고, 누적 강수량은 빠진 시간을 다음 실행 때 스스로 메우므로
  지연되어도 값은 맞습니다. 분 단위 정시가 필요하면 외부 스케줄러를 붙이세요.
- **cron은 UTC 기준**입니다. `5 * * * *` 는 매시 5분이라 KST에서도 매시 5분이라 그대로 둬도 됩니다.
- **60일간 저장소 활동이 없으면 스케줄이 자동 비활성화**됩니다.
  이 워크플로는 매시 커밋하므로 해당되지 않습니다.
- **Actions 무료 한도** — 공개 저장소는 무제한, 비공개는 월 2,000분입니다.
  한 번 실행이 1분 남짓이라 매시 × 30일 ≈ 720분, 비공개로 둬도 한도 안입니다.
- **공개/비공개 판단** — 저장소를 공개하면 `regions.json` 이 그대로 노출됩니다.
  어느 지역 8곳을 묶어 보고 있는지가 드러나므로, 비공개 저장소를 권합니다.
  Actions 한도는 위처럼 비공개로도 충분합니다.

### 내 PC에서 돌릴 때

정적 배포와 별개로 로컬 서버도 그대로 됩니다.

```bash
cp .env.example .env          # DATA_GO_KR_KEY 채우기
pip install -r requirements-server.txt
set -a && source .env && set +a
python server.py              # http://localhost:8000
```

매시 05분에 수집하고 `지금 갱신` 버튼이 살아납니다.
1회만 돌려보려면 `python collect.py` — `public/data.json` 만 만들고 끝납니다.

# 4. 화면 항목이 어디서 오는가

| 항목 | 원천 |
|---|---|
| 개황 | `getVilageFcst` SKY·PTY → 하늘상태 한 단어 + 이후 강수 예고 |
| 미세 / 초미세 | `getCtprvnRltmMesureDnsty` (측정소 자동탐색) |
| 기온 | `getVilageFcst` TMN~TMX (오늘 최저~최고) |
| 풍향/풍속 | `getVilageFcst` VEC·WSD, 기준시각 이후 6시간의 평균 풍향 + 풍속 범위 |
| 일일 누적 강수량 | `getUltraSrtNcst` RN1 을 00시부터 시간별로 모아 합산 |
| 일일 예상 강수량 | `getVilageFcst` PCP 를 기준시각~익일 09시에서 연속 시간대로 묶음 |
| 기상특보 | `getWthrWrnList` → `getWthrWrnMsg` 통보문에서 해당 시·군 발효분만 추출 |

**참고사항 반영**

1. **누적 강수량** — 기준시각까지 그날의 합입니다. 00시부터 매시 실황을 채워 넣고, 빠진 시간이 있으면
   다음 실행 때 그 시각을 다시 호출해 스스로 메웁니다. 화면에 `결측 N시간`이 뜨면 아직 못 채운 것입니다.
   기상청 공식 일강수량이 아니라 시간당 실황의 합이라는 점은 알고 쓰셔야 합니다.
2. **예상 강수량** — 기준시각 다음 시간부터 익일 09시까지, 강수가 이어지는 구간끼리 묶어
   `01:00~05:00 (17mm)` 로 적습니다. 끝 시각은 마지막 강수 시각 +1시간입니다
   (01·02·03·04시에 비 → `01:00~05:00`). 종료 시각은 `collector.py` 의 `FORECAST_END_HOUR` 로 바꿉니다.
3. **매시 최신화** — Actions `cron: "5 * * * *"`, 로컬은 `server.py` 의 `REFRESH_MINUTE`.

# 5. 지역 손보기 — `regions.json`

지금 위경도는 각 시·군청 소재지 기준이라 **한 번 확인하시길 권합니다.**
날씨누리에서 원하는 지점을 띄운 뒤 주소창 `#dong/{행정동코드}/{위도}/{경도}/...` 에서
위도·경도를 복사해 넣으면 됩니다. 격자(nx, ny)는 코드가 계산합니다.

현재 격자 — 양평 69,125 · 경산 91,90 · 사천 80,71 · 함안 86,77 ·
성주 83,91 · 세종 66,103 · 계룡 65,99 · 임실 66,84

| 필드 | 설명 |
|---|---|
| `lat` / `lon` | 날씨누리 URL에서 복사 |
| `wrnStnId` | 특보·개황 발표관서. 서울인천경기 `109`, 강원 `105`, 충북 `131`, 대전세종충남 `133`, 전북 `146`, 광주전남 `156`, 대구경북 `143`, 부산울산경남 `159`, 제주 `184` |
| `sidoName` | 에어코리아 시도명 (`경기` `경북` `경남` `세종` `충남` `전북` …) |
| `umdName` / `sggName` | 측정소 자동탐색용 읍·면·동, 시·군·구 |
| `airStation` | 자동탐색이 엉뚱한 측정소를 잡으면 측정소명을 직접 적어 덮어씀 |
| `warnKeywords` | 특보 통보문에서 이 지역을 골라낼 문자열. 보통 시·군명 그대로 |

탐색된 측정소는 `state/stations.json` 에 캐시되고 화면 하단에 지역별로 표시됩니다.
바꾸려면 그 파일을 지우거나 `airStation` 을 직접 지정하세요.

# 6. 그 밖에

- **기상특보**는 통보문에서 `폭염경보 : 대구, 경상북도(경산, 영천…)` 같은 줄을 읽어 해당 시·군만 뽑습니다.
  `해제`·`예비` 가 들어간 줄은 제외합니다. 표기가 바뀌면 `collector.py` 의 `WARN_LINE` 정규식만 손보면 됩니다.
- **개황**은 표에 한 단어로 넣었습니다. 기상청 개황 통보문은 시·도 단위로만 나오므로
  전문은 표 아래 접힘 영역에 관서별로 따로 붙였습니다.
- `표 복사` 버튼은 표를 TSV로 복사합니다. 한글(HWP)이나 엑셀에 붙이면 셀이 나뉘어 들어갑니다.
  인쇄(Ctrl+P)하면 배경과 버튼을 뺀 흑백 표로 나옵니다.
- 풍향 칸의 기호는 기상 관측 기호(wind barb)입니다. 깃대는 바람이 불어오는 쪽을 가리키고
  짧은 깃 5노트 · 긴 깃 10노트 · 삼각 깃 50노트, 3노트 미만이면 빈 원(정온)입니다.
