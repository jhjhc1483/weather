# 🌤️ 대한민국 8개 주요 지역 실시간 기상 & 미세먼지 예보 대시보드

> **스마트하고 한눈에 들어오는 맞춤형 기상 통합 대시보드**  
> 기상청 초단기실황, 초단기예보, 단기예보 및 에어코리아 미세먼지 측정 데이터를 자동 수집·통합하여 실시간으로 표출합니다.

---

## 📌 주요 특징 (Key Features)

- **8개 주요 지역 정밀 예보**: 양평, 경산, 사천, 함안, 성주, 세종, 계룡, 임실 8개 타겟 지역의 핀포인트 격자 좌표 기반 날씨 표출
- **3대 공공 데이터 통합 수집**:
  1. 기상청 초단기실황 (`T1H`, `PTY`, `WSD`, `VEC`)
  2. 기상청 초단기/단기예보 (`SKY`, `PCP`, `TMN`, `TMX`)
  3. 에어코리아 실시간 미세먼지/초미세먼지 (`PM10`, `PM2.5`) 및 1차 측정소 점검 시 **2차 백업 관측소 자동 전환 (Fallback)**
- **기상특보 자동 파싱**: 폭염경보, 폭염주의보, 열대야, 호우 등 기상청 특보 발효 시 해당 지역 하이라이트 표출 및 세로 정렬
- **일일 예상 강수량 확장**: 현재 시각부터 **다음날 오전 09:00까지**의 예상 강수 시간대별 강수량 표출 (`(내일)` 라벨 구분)
- **스마트 폴링 & 웹 알림**: [지금 갱신] 클릭 시 백그라운드 수집 완료를 자동 감지하여 토스트 및 브라우저 데스크톱 알림 제공
- **다크 / 라이트 모드**: 선호도를 `localStorage`에 자동 저장하고 우측 상단 원형 아이콘 버튼으로 즉시 전환 지원
- **스마트폰 모바일 반응형**: 모바일 화면에서도 깨짐 없이 가시성을 극대화한 반응형 레이아웃

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Data Collection**: Python 3.x (`requests`, `python-dotenv`)
- **Automation & Serverless**: GitHub Actions (`workflow_dispatch`), Vercel Serverless Functions (`api/trigger.py`)
- **Data Storage**: GitHub Repository JSON File (`data/weather.json`)
